# 定时公告

## 已确认范围

管理一条公告，包含开启开关、Markdown 内容、开始时间和结束时间。导航栏在上、公告在下，共用正常文档流中的 sticky 容器，滚动时保持置顶。首页和实例详情页共享该区域。弹窗和菜单位于其上方。长公告限制为视口高度的 30%，上限 16rem，支持内部滚动。

Markdown 支持标题、段落、强调、列表、引用、代码、表格和链接。禁用原始 HTML、图片及非 HTTP/HTTPS/mailto 链接；预览与发布使用同一个渲染器。访客不能关闭公告。

## 配置与管理

配置保存于 `theme_settings.announcement`，字段为 `enabled`、`content`、`startsAt`、`endsAt`。兼容点分隔字段及 JSON 字符串配置，默认关闭。

Komari 后台通过主题清单声明管理字段。后台时间输入使用带时区的 ISO 日期，例如 `2026-09-05T18:00:00+08:00`。后台通用表单的校验能力由宿主决定；无效公告在前台不展示。

登录前台后，主题设置顶部提供“公告管理”，包含日期时间选择、当前输入时区、Markdown 即时预览、保存、立即关闭和已发布状态。开启时禁止发布空内容、无效时间、反向区间或已结束区间。关闭状态可保留草稿。

保存前读取服务器配置，合并公告；同一页面的公告和主题写入排队执行。主题外观修改排除公告字段，避免旧快照覆盖公告。保存成功才更新已发布公告；失败显示错误并保留输入。

## 生命周期

显示条件为：开启、内容非空、合法时间、开始早于结束且当前时间位于 `[开始时间, 结束时间)`。浏览器每秒检查，恢复标签页时立即重新检查。时间以明确的时区解析为绝对时间；当前时刻依赖访客设备时钟。

页面每 30 秒拉取公开设置，聚焦、联网及恢复可见时也刷新。请求超时为 10 秒。网络失败保留当前公告，但仍执行到期隐藏。尚未加载配置时不展示横幅。发布后已打开页面通常在 30 秒加请求耗时内收到更新。

到期只隐藏横幅，保留配置及开启字段；不由访客浏览器写回后台开关。整个站点不可访问时无法保证公告可见，独立维护页不在本次范围。

## 验证

检查开始前、开始时、结束前、结束时、关闭、空内容、无效日期及时间区间；检查不同时区对应同一时刻、危险链接、两种配置结构。运行 TypeScript、定向 ESLint 和生产构建。浏览器验证吸顶、移动端长内容、弹窗层级、Markdown 预览及模拟接口下的保存与到期。
